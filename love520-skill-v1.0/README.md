
# 💖 520 浪漫表白技能

一个可自定义配置的浪漫表白页面生成器，用程序员的方式表达爱！

## ✨ 功能特性

### 🎨 炫酷视觉效果
- **粒子动画背景** - 100+彩色粒子在屏幕上自由飘动
- **跳动大爱心** - 中心有一个脉动的红色爱心
- **浮动爱心雨** - 各种爱心emoji从底部升起
- **霓虹发光效果** - 标题和文字有漂亮的光晕
- **玻璃拟态设计** - 现代化的UI效果

### 🎯 互动功能
- **"我愿意"按钮** - 点击后弹出惊喜弹窗，爱心如雨下
- **"再想想"按钮** - 鼠标靠近时会调皮地躲来躲去，多次后消失

### ⚙️ 自定义配置
- ✅ 自定义标题和副标题
- ✅ 自定义表白内容
- ✅ 自定义代码块
- ✅ 自定义配色方案
- ✅ 自定义按钮文字
- ✅ 预设模板（经典浪漫、程序员的爱、永恒约定）
- ✅ 配置保存和加载

## 🚀 快速开始

### 安装依赖

```bash
pip install PyQt5
```

### 启动程序

#### Windows
```bash
cd love520-skill
python run.py
```

或者双击 `run.bat`

#### Linux/Mac
```bash
cd love520-skill
python3 run.py
```

## 📖 使用说明

### 1. 基础配置
- **主标题** - 页面最上方的大标题
- **副标题** - 标题下方的小字
- **表白语** - 主要的表白内容，支持换行
- **高亮文字** - 表白语中需要强调的文字
- **按钮文字** - 自定义两个按钮的文字

### 2. 高级配置
- **代码块** - 修改页面上显示的代码
- **颜色配置** - 自定义配色方案
- **特效配置** - 调整粒子数量等

### 3. 预设模板
提供了三个预设模板，快速切换不同风格：
- 经典浪漫 - 粉色系，温馨浪漫
- 程序员的爱 - 绿色系，科技感十足
- 永恒约定 - 紫色系，神秘浪漫

### 4. 生成和保存
- **生成并预览** - 直接在浏览器中打开
- **保存HTML** - 将生成的页面保存为文件
- **保存/加载配置** - 保存你的配置以便下次使用

## 🎨 技术栈

- **Python** - 后端逻辑
- **PyQt5** - 图形化界面
- **HTML5 + CSS3 + JavaScript** - 页面展示
- **Canvas** - 粒子动画

## 💡 使用示例

### 简单使用
```python
from love520_skill import Love520Generator, LoveConfig

# 创建配置
config = LoveConfig()
config.title = "💕 亲爱的，我爱你 💕"
config.love_message = "从遇见你那一刻，我的世界变得不同..."

# 生成页面
generator = Love520Generator(config)
generator.open_in_browser()
```

### 保存为文件
```python
generator.save_to_file("my_love.html")
```
